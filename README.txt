DIGICAM ARCHIVE — VERSION 2

FITUR
- Upload banyak foto sekaligus.
- Pilih album tujuan SEBELUM upload.
- Album baru otomatis dipilih setelah dibuat.
- Filter album dan pencarian nama foto.
- Pindahkan foto ke album lain dengan membuka foto lalu mengubah pilihan album.
- Download foto satu per satu.
- Pengelolaan album; menghapus album memindahkan fotonya ke Unsorted.
- Migrasi otomatis dari penyimpanan versi 1 pada browser yang sama.

CARA MENJALANKAN
1. Extract DIGICAM-ARCHIVE-V2.zip.
2. Buka folder hasil extract di VS Code.
3. Install ekstensi Live Server (Ritwick Dey), jika belum ada.
4. Klik kanan index.html > Open with Live Server.
5. Pilih album pada bagian UPLOAD TO ALBUM.
6. Klik ADD PHOTOS dan pilih foto dari laptop.

FOTO CANON A3400
Sambungkan kamera ke laptop, buka This PC dan cari kamera/SD card. Salin foto dari folder DCIM ke laptop. Setelah itu upload dari website. Jika kamera tidak terdeteksi, gunakan card reader SD yang sesuai.

PENYIMPANAN DAN BACKUP
- Data disimpan di localStorage browser pada perangkat tersebut; tidak dikirim ke internet.
- Kapasitas browser terbatas. Foto resolusi tinggi atau jumlah besar bisa membuat penyimpanan penuh.
- Selalu simpan foto asli di folder laptop/drive eksternal. Jangan jadikan website sebagai satu-satunya backup.
- Data versi 1 hanya dapat dimigrasikan jika masih ada di browser yang sama.
- Jika ingin reset atau memindahkan koleksi ke browser lain, diperlukan fitur export/import backup (belum termasuk).
